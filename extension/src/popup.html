This browser does not give extensions access to browsing history. The extension cannot read any history here, so it cannot contribute. Use desktop Chrome, Edge or Firefox.

What this reads: your browser history for the last 7 days, on this computer only. Each site is matched to one of eight coarse categories (Travel, Food, Tech...). Unknown sites are ignored.

What leaves: one model update, clipped and with random noise added here, plus the number of visits. No URLs, no history, no categories list. The server cannot tell which update is yours from its contents.

Your controls: pause, delete everything this extension stores, and a log of every send below. Contributing is always a button you press.
